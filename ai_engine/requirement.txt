# Data handling
#
# pandas is held at 2.x ON PURPOSE — this is NOT the contemporaneous version.
# pandas 3.0.5 was already current on 2026-08-02, but pandas 3 changed string
# columns to the new `str` dtype, where a NULL reads back as float `nan` instead
# of `None`. agents/supervisor/nodes.py:eda_enrichment_node is written for the
# 2.x semantics and breaks silently under 3.x:
#
#   * `if symbol is None:` never fires   -> the extra_params fallback is dead code
#   * `footprint or package` returns nan -> nan is TRUTHY, so no fallback happens
#   * `pins_json` becomes nan, not None  -> absent pinout data reads as present
#   * `enriched_count` counts nan as a hit -> false "enriched" signal
#   * json.dumps emits a bare `NaN`      -> invalid JSON that JSON.parse rejects
#
# All five verified empirically. Lift this cap only after nodes.py uses a
# null check that catches nan (e.g. pandas.isna) rather than `is None`/`or`.
