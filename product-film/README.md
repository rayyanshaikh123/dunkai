# Dunk AI launch film

33.5-second SaaS launch film, 3840 x 2160 at 60 fps. No narration. Uses the product's graphite background, blue accent, Figtree headings and Google Sans Code technical text, with glass panels and animated Kevin branding.

Run `npm install`, `node scripts/audio.cjs`, then `npm run dev`. Select `DunkAI-Launch-4K`.

## Story

| Seconds | Beat |
|---|---|
| 0-3 | Problem: one idea, too many tools and handoffs |
| 3-5 | Product reveal: Meet Dunk AI |
| 4.5-10 | Type the environmental-monitor prompt and submit |
| 9.5-14 | Requirements become an architecture |
| 13.5-19.5 | Components resolve into BOM rows |
| 19-24.5 | Physical board assembly, routing and macro camera move |
| 24-29 | Firmware and hardware connection |
| 28.5-33.5 | Connected engineering package, brand and Start building CTA |

Scenes overlap by 0.5 seconds. The 1920 x 1080 design canvas scales to UHD. Typography and SVG render at output resolution; the 3D canvas uses DPR 2. Animation is deterministic and sampled at 60 fps.

## Assets and accuracy

- Logo and animated `kevin.webp` come from the frontend's public assets. AnimatedImage controls the mascot timing.
- Figtree and Google Sans Code match `frontend/app/layout.tsx`. Local font files use their included OFL licenses.
- Device concept comes from `ai_engine/data/profiles/env-sensor-node.json`.
- Part IDs, net labels, four-layer board and 100 x 60 mm dimensions come from `ai_engine/agents/component_agent/fixed_pcb_ir.json`, copied to `src/pcb-ir.json`.
- Board geometry is an illustrative visualization of the IR. Firmware is illustrative pseudocode, not a compiled or device-tested artifact.
- The supplied `ddd.mp4` informed camera focus, prompt zooms, flowing transitions and restrained closing branding. Reference assets were not copied.
- Audio is an original deterministic 48 kHz stereo instrumental and synchronized Foley generated by `scripts/audio.cjs`.

## Removed scenery

Home and greenhouse scenery scenes are excluded from the film and scene registry at the user's request. Their unused generated assets remain in public for recoverability. They were generated with the built-in image tool: sunlit ivory modern home with a plaster arch, limestone sideboard and plants; airy glass-roof greenhouse with plants in dawn light. Local files: `public/scenery-home.png`, `public/scenery-greenhouse.png`.

## Validation and export

ESLint and TypeScript pass. Story frames were rendered and visually checked; the 4K composition is registered at 60 fps. Browser playback review was unavailable in this session.

Export when requested:

```sh
npx remotion render DunkAI-Launch-4K out/dunk-ai-launch.mp4 --codec=h264 --crf=16 --pixel-format=yuv420p
```
